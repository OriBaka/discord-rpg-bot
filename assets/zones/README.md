# Zone illustrations

Nine AI-generated pixel-fantasy environment illustrations created for this bot.
PNG files are optimized to at most 1280×720 with an indexed palette; total about 4.6 MiB.
No external image host or image-generation API is required at runtime.

Used in `%info zone <id>` and hunt result embeds (including slash equivalents).
`zone_pixel_art_v1` migration replaces previous zone image URLs once. Later admin
HTTPS overrides remain respected; clearing the URL restores the bundled image.
Monster thumbnails are preserved independently. No Seven Sins swords are awarded
or made obtainable; these assets are environmental illustrations only.
